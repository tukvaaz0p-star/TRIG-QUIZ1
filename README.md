# TRIG QUIZ

Простой сайт для одного занятия: без фреймворков, сложного оформления и платных сервисов.

## Запуск

Нужен **Node.js 18 или новее**.

1. Распакуй архив и открой папку `TRIG-QUIZ` в VS Code.
2. Открой терминал в этой папке.
3. Выполни `node server.js` (или `npm start`).
4. Открой в браузере `http://localhost:3000`.

**Важно:** `index.html` теперь нельзя просто открывать двойным нажатием. Для онлайн-режима необходим запущенный `server.js`.

Для проверки с телефона в одной Wi-Fi-сети узнай IPv4-адрес компьютера через `ipconfig` и открой на телефоне `http://АДРЕС_КОМПЬЮТЕРА:3000`. Возможно, потребуется разрешить входящие подключения Node.js в брандмауэре Windows. Это работает только пока компьютер включён и сервер запущен.

Для доступа из интернета потребуется разместить Node.js-сервер на хостинге с **постоянным хранилищем**. GitHub Pages недостаточно: он не запускает Node.js. Не выкладывай папку `data` и файл с результатами в публичный репозиторий.

## Вход

Одна форма с полем **Логин**:
- Студент: `Имя Фамилия`.
- Преподаватель: `1488`.

Код можно изменить через переменную окружения `TEACHER_CODE`, по умолчанию `1488`. Проверяется на сервере, в браузерном JS он не хранится. Тем не менее **четырёхзначный код слабый и не защищает от человека, который его узнал**. Для одноразового класса это упрощённый вариант, не профессиональная система авторизации.

## Механика

- 10 вопросов из `questions.json` (сейчас **временные демонстрационные** из старого прототипа).
- 4 варианта, один правильный, индивидуальное случайное перемешивание.
- 20 секунд на вопрос; сервер проверяет ответы и считает результат. Скорость ответа не влияет на баллы.
- При пропадании связи таймер примерно через несколько секунд перестаёт расходоваться. После восстановления продолжается с сохранённого значения. Этот упрощённый механизм можно обойти намеренным отключением связи; не использовать для строгого экзамена.
- Одна попытка на сочетание имени и фамилии. Из того же браузера попытка восстанавливается автоматически. Одинаковые имена, подмена и очистка хранилища браузера могут создавать проблемы, так как полноценной идентификации нет.
- Закрытие теста запрещает новые попытки, но не мешает начатым закончить.
- Преподаватель видит в реальном времени статусы всех участников, но баллы только завершивших тест.
- У студентов после завершения написано только «Тест завершён». Баллы и разбор открываются после публикации преподавателем.
- Публикация доступна только после закрытия теста и завершения всех начатых попыток.
- Экран `ТОП-3 на доску` показывает три лучших **места**; при равенстве баллов несколько студентов делят место.

## Очистка после проверки

В панели преподавателя нажми **Удалить результаты тестирования** и напиши `ОЧИСТИТЬ`.

Очищается только `data/results.json`: все участники, ответы и результаты. **`questions.json` и `data/settings.json` сохраняются без изменений**. Чтобы снова открыть тест после очистки, используй кнопку «Открыть тест»; она также скрывает старую публикацию. У бывших участников с устаревшим токеном сайт автоматически покажет новый вход.

## Файлы

```
TRIG-QUIZ/
├── server.js            сервер без внешних библиотек
├── package.json
├── questions.json       10 вопросов, правильные ответы и объяснения, серверный файл
├── public/
│   ├── index.html       единая страница входа
│   ├── style.css        простая светлая тема
│   └── app.js           интерфейс студента и преподавателя
└── data/                создаётся при запуске, не выкладывать публично
    ├── settings.json    открыт/закрыт и публикация
    └── results.json     результаты, удаляются кнопкой очистки
```

Если изменяешь `questions.json`, перезапусти сервер. Перед реальным занятием замени временные вопросы на согласованные с преподавателем и проверь, что ответы правильные.

## Ограничения

- Нужен один работающий Node.js-сервер. Файловая база подходит для небольшого класса на одном экземпляре сервера, не для масштабируемого хостинга с несколькими копиями приложения.
- Папка `data` должна храниться на постоянном диске: на некоторых хостингах файлы пропадают после перезапуска контейнера.
- Простой код `1488` можно угадать или узнать. Не используйте такой подход для важных персональных данных и настоящих экзаменов.
- Сохранённые на компьютере результаты содержат имена студентов. После тестирования удалите их кнопкой очистки и не публикуйте файлы базы в интернет.
